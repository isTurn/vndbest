# VNDB 1.0.7

内置浏览器的工具栏上多了「用外部浏览器打开」按钮，TouchGal 外链的中转页（广告 / 5 秒等待）会自动跳过，跨站搜索脚本同步到上游 v2.6.1，另外删掉了此前一直在后台跑的匿名使用统计上报。

## 新增

- **内置浏览器「用外部浏览器打开」**：内置浏览器顶部工具栏右侧（和前进 / 后退 / 刷新同一行）多了一个按钮，点一下就把当前页面交给系统浏览器或你自选的那个浏览器。站内无刷新跳转后的地址也能跟对。不想要的话可以在「设置 → 跳转」里关掉。
- **TouchGal 专用开关**：「设置 → 跳转 → TouchGal 用内置浏览器打开」，**默认开启**。开启时不管跨站搜索的打开方式怎么设，TouchGal 都先进内置浏览器，等页面正常加载完，再决定要不要用上面的按钮甩给外部浏览器。
- **TouchGal 过渡页自动跳过**：在 TouchGal 点外链本来会先进「即将离开本站…5 秒」的中转页，现在直接跳过去。两层机制：点链接时先把真实地址解析出来、根本不进中转页（绝大多数场景走这条）；万一人已经在中转页上了，也会立刻解析 `url` / `target` / `go` 参数、`meta refresh` 和「继续访问」链接跳走，不用干等。

## 变更

- **跨站搜索用户脚本升级到 v2.6.1**：`@run-at` 改为 `document-start`、`@match` 扩到 TouchGal 全站，新增「外链跳转页自动跳过」——遇到中转页会自己解析 `url` / `target` / `go` 参数、`meta refresh` 和「继续访问」链接，直接到位。站点表仍然 41 项，应用内的跨站搜索数据不受影响。
- **「关于」的第三方脚本版本号**：VNDB跨站搜索从 v2.5.14 更正为 v2.6.1，并补登 TouchGal 自动跳转 v2.2。

## 移除

- **匿名使用统计上报**：之前每次启动会往一个第三方 Worker（`workers.hekinyan.vip/v1/active`）POST 安装 ID、设备型号、系统版本、UA，而且没有开关。现在整段逻辑和常量都删了，两个相关的 `localStorage` 键也不再写入。**除了 VNDB 官方 API 和内嵌页面，应用不会再往任何第三方服务发请求。**

## 修复

- **按钮图标不显示**：`ic_open_external` 只在运行时按名字查找，被 `shrinkResources` 当成无用资源裁掉了，现在用 `res/raw/keep.xml` 保住。
- **内置浏览器里点 TouchGal 外链仍要等 5 秒**：之前只移植了跨站搜索脚本的「搜索填入」部分，跳过过渡页的逻辑整个缺失，这次补上了。
