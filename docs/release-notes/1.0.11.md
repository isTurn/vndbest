# VNDB 1.0.11

分类浏览重新排版，性别图标换成一眼能分的 ♀ / ♂ / ⚥，以图搜作品多了 SearchBox 识别源和图片大图查看。

## 新增

- **SearchBox 识别源**：以图搜作品页顶部可切换 `AnimeTrace` / `SearchBox`，选择会被记住。SearchBox 会同时给出 VNDB 作品条目、图中角色和一段文字说明
- **搜索页直接选图**：「以图搜作品」入口直接调起相册，选完自动进入识别页
- **大图查看**：识别页点预览图可全屏查看

## 变更

- **分类浏览两列**：图标在左、标题在右，去掉了卡片下方「查看 X 列表」的小字，二级页面顶部的副标题也一并去掉
- **角色排在人物前**：分类顺序调整为 作品 / 版本 / 角色 / 人物 / 标签 / 特征
- **性别图标重绘**：原来三个图标在小尺寸下几乎没有区别，现改为 ♀（女，粉色）、♂（男，蓝色）、⚥（双性，红色）

## 修复

- **识别超时报英文原文**：以前网络慢会直接显示 `signal is aborted without reason`，现在改为可读的超时提示，并会自动改用原生请求重试一次

---

- 支持从 1.0.7 以上版本覆盖安装；1.0.5 及更早的包签名不同，需先卸载
- 包名 `com.vndb`，versionCode 10011
- 图片识别由 [AnimeTrace](https://ai.animedb.cn/) 与 [SearchBox](https://www.searchbox.club/) 提供
