# VNDB 1.0.14

收藏评分支持自定义小数输入，收藏状态、评分、编辑按钮合并到同一行；角色卡片名字下方显示声优并可跳转声优详情；修复系统三键导航遮挡详情页与底部弹层的问题；作品网格按屏幕宽度自动切换手机 3 列 / 平板 4 列，作品详情的开始与结束日期放到同一行。

## 新增

- **自定义评分（支持小数）**：编辑收藏时可以直接输入 1–10 的任意小数（如 7.5），星星会按数值点亮，保存后详情里显示实际小数，重新打开弹窗也会正确回显
- **角色卡片显示声优**：角色详情名字下方列出声优，点击可跳转到对应的声优详情页
- **网格自适应列数**：作品列表和发售列表的网格模式，手机上显示 3 列封面，平板上显示 4 列，旋转屏幕或改变窗口大小时自动重排

## 变更

- **收藏状态区合并成一行**：「收藏状态」「评分」「编辑」放到同一行，编辑按钮位于最右侧；去掉原来重复显示已选标签的一排小标签
- **开始/结束日期同行**：作品详情里开始日期和结束日期显示在同一行

## 修复

- **虚拟导航键遮挡详情页底部**：开启系统三键导航后，导航栏会盖住页面最底部内容导致无法点击。现在页面会预留底部安全区，最后一行内容完整可见可点
- **底部弹层按钮被导航栏压住**：操作表、投票、筛选、收藏编辑等贴底弹层的底部按钮区也预留了安全区，宽屏下不会出现多余留白
