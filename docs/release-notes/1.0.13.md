# VNDB 1.0.13

作品页上半区不再套一层卡片框，列表封面缩小后四周留白、四角仍是圆角；游戏时长弹窗的「投票类型」和「阅读速度」都改成左边标题、右边分段按钮；跨站搜索点开绯月会以桌面版打开并自动填入关键词。

## 新增

- **绯月以桌面版打开并自动搜词**：跨站搜索里点「绯月」不再进移动版页面，而是用桌面版打开，并把当前作品名填进站内搜索框自动提交

## 变更

- **时长弹窗的投票类型改成分段按钮**：「计入平均 / 不计入」从两个方块按钮变成与「阅读速度」一致的胶囊分段，标题在左、按钮在右
- **阅读速度不再换行**：标题和按钮保持在同一行，长文案也不会把按钮挤到下一行
- **作品页上半区去掉卡片框**：封面和基本信息不再套一层带边框和底色的卡片，内容直接铺在页面上
- **列表封面缩小留白**：作品、版本、角色列表的封面比卡片小一圈，四周留出空白，四角保持圆角
- **瀑布流封面固定比例**：两列布局的封面统一成 3:4 比例，封面下沿的分隔线去掉了

## 修复

- **绯月进去是移动版、搜索词没填**：该站点按 User-Agent 返回两套页面，移动版没有搜索框也不认 URL 里的搜索参数。现在固定用桌面版打开并自动填词
- **瀑布流只看到评分、看不到作品名**：两列布局的封面高度原先跟着图片自身比例走，竖版封面会把卡片下方的标题整块顶出可视范围。现在封面固定成 3:4 比例盒，作品名、副标题和徽章都能正常显示

---

- 支持从 1.0.7 以上版本覆盖安装；1.0.5 及更早的包签名不同，需先卸载
- 包名 `com.vndb`，versionCode 10013
- 绯月的站内搜索需要登录，未登录时会先停在登录页，登录成功后会自动填入关键词
