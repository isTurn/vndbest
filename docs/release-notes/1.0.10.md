# VNDB 1.0.10

以图搜作品上线：选一张图就能认出作品并跳到 VNDB 页面，也能从其他应用直接把图片分享过来。内置浏览器的下载改为交给 1DM+ / ADM。

## 新增

- **以图搜作品**：搜索页搜索框下方新增入口。选图后本地压缩再上传识别，返回作品名与角色名，并用作品名反查 VNDB 条目（封面 / 标题 / 原名 / 年份），点一下进作品详情页；没匹配上的可一键转 VNDB 搜索
- **识别结果标注**：整体置信度偏低标「置信度较低」，AI 生成图单独提示
- **从其他应用分享图片**：系统分享面板出现「VNDB / 以图搜作品」两行，从相册、QQ、浏览器等分享过来即自动跳到识别页开跑
- **冷启动与热启动都支持**：App 没在运行也能被分享面板拉起；已在后台则回前台后自动接上；单图与多图都支持（多图取第一张）

## 变更

- **内置浏览器下载交给下载管理器**：优先 1DM+ / ADM，没装则退回系统默认处理器，仍不行才由内置浏览器自己落盘
- **下载管理器可见性声明**：`<queries>` 补上 1DM+ / ADM 包名，Android 11+ 才能定位到它们
- **分享入口与桌面图标分开**：分享面板里的入口名是「以图搜作品」，桌面图标仍是「VNDB」

## 修复

- **内置浏览器点下载没反应**：下载事件不再被静默丢弃
- **分享图片进来后停在首页**：不同应用塞图位置不统一，改为四路依次兜底

---

- 支持从 1.0.7 / 1.0.8 / 1.0.9 覆盖安装；1.0.5 及更早的包签名不同，需先卸载
- 包名 `com.vndb`，versionCode 10010
- 图片识别由 [AnimeTrace](https://ai.animedb.cn/) 提供
