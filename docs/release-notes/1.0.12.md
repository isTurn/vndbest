# VNDB 1.0.12

仪表盘的「即将发布」可以查看全部了，「最新汉化」卡片删掉后能在设置里重新打开；相关作品默认显示同人作并在条目上标注，关系标签全部汉化，无性别角色补齐图标。

## 新增

- **即将发布可查看全部**：「即将发布」标题右侧加了「查看全部」按钮，点进去是今天以后的全部发售列表，从最近要发售的开始排
- **「最新汉化」卡片开关**：设置 → 外观与语言里新增「最新汉化卡片」开关，关掉即从仪表盘移除，打开即恢复
- **同人作默认显示**：作品页的相关作品默认包含同人作，不用每次手动打开开关
- **关联作品标注「同人作」**：非官方关联的条目上会多一个「同人作」小徽章
- **无性别角色补齐图标**：性别未知/无性的角色现在显示 ⊖ 样式的图标，不再空着

## 变更

- **关系标签汉化**：相关作品里的 `orig`、`par`、`seq` 等英文原码全部换成中文——原作、本篇、续作、前作、同设定、另版、共享角色、外传·番外、系列、同人

## 修复

- **「即将发布」查看全部的排序反了**：原来按新发售的排前面，等于把最远的排最前；现在从最近要发售的开始排
- **「最新汉化」卡片删掉后找不回来**：现在在仪表盘删掉它，设置里的开关会同步关闭；想找回来去设置里重新打开即可
