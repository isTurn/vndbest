# VNDB 1.0.12

仪表盘的「即将发布」可以查看全部了；相关作品默认显示同人作并在条目上标注，关系标签全部汉化，无性别角色补齐图标。

## 新增

- **即将发布可查看全部**：「即将发布」标题右侧加了「查看全部」按钮，点进去是今天以后的全部发售列表
- **同人作默认显示**：作品页的相关作品默认包含同人作，不用每次手动打开开关
- **关联作品标注「同人作」**：非官方关联的条目上会多一个「同人作」小徽章
- **无性别角色补齐图标**：性别未知/无性的角色现在显示 ⊖ 样式的图标，不再空着

## 变更

- **关系标签汉化**：相关作品里的 `orig`、`par`、`seq` 等英文原码全部换成中文——原作、本篇、续作、前作、同设定、另版、共享角色、外传·番外、系列、同人

---

- 支持从 1.0.7 以上版本覆盖安装；1.0.5 及更早的包签名不同，需先卸载
- 包名 `com.vndb`，versionCode 10012
