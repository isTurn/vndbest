# VNDB 1.0.15

首屏体积减少约 63%，首页再次打开直接读本地缓存，跨站搜索在浏览器打开后立即填入关键词。

## 优化

- **启动更快**：首屏 JS 由约 1.49 MB 降到约 552 KB（gzip 348 KB 降到 173 KB），样式文件也小了约 6 KB
- **首页更快**：统计、最新发售、即将发售、生日数据 5 分钟内直接读本地缓存，下拉刷新仍会取最新；保存的搜索最多 2 路同时加载；今日生日先显示，明日生日不再拖住今日内容
- **跨站搜索更快**：浏览器窗口一打开就填入关键词，TouchGal 与绯月首次填入由约 2.6 秒降到百余毫秒

## 修复

- **缓存过期时间被重置**：本地缓存读进内存时不再把过期时间推后，数据不会长期停在旧内容
- **刷新被旧数据覆盖**：强制刷新时旧请求晚到不会再覆盖新数据
- **生产与沙箱串用**：两套环境的缓存互不相干
- **重复开窗**：连续点击跨站搜索只更新关键词，不会多开窗口，也不会填到别的标签页
- **关闭后仍在注入**：关闭浏览器后立即停止后续脚本注入
