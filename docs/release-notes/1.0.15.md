# VNDB 1.0.15

这一版主要优化加载速度：首屏 JS 体积减少约 63%，首页数据冷启动直接读本地缓存，跨站搜索在浏览器打开后立刻填入关键词，不再等整页加载完；同时修掉了缓存过期时间被延长、缓存键未区分生产与沙箱等隐患。

## 变更

- **打开更快**：未使用的 Ionic 组件不再打进首屏，首屏 JS 由约 1.49 MB（gzip 348 KB）降到约 552 KB（gzip 173 KB），样式文件也小了约 6 KB
- **首页更快**：统计、最新发售、即将发售、生日数据在 5 分钟内的再次打开直接读本地缓存，手动下拉刷新仍会拉取最新数据；保存的搜索最多 2 路同时加载；今日生日先显示，明日生日不再拖住今日内容
- **跨站搜索更快**：点击跨站搜索后，浏览器窗口一建立就开始填入关键词，并且会在页面加载过程中按间隔重试，直到填上为止
- **缓存更可靠**：生产与沙箱的缓存互不串用；同一请求并发时只发一次网络请求；本地数据库卡住时 200ms 内改用网络加载，不再长时间空白

## 修复

- **缓存永不过期**：本地磁盘缓存被读进内存时曾被重置为 5 分钟，导致长期不刷新数据，现在保留原本的过期时间
- **刷新被旧数据覆盖**：强制刷新时，如果旧请求更晚返回，会把新数据覆盖掉；现在旧响应不会写回缓存
- **连续点击重复开窗**：打开过程中再点一次只会更新关键词，不会多开一个浏览器，也不会把关键词填到别的标签页
- **关闭后仍在注入**：关闭浏览器后立即停止后续脚本注入，不再对已关闭的窗口执行操作

## 测试

- 新增 10 项自动化回归（`node scripts/test-loading-performance.mjs`），覆盖缓存合并、刷新竞态、私有数据不缓存、生产/沙箱隔离、本地数据库阻塞回退、浏览器提前注入与失败清理，全部通过
- 实机（Lenovo TB321FU / Android 16）三次冷启动：网页首次内容绘制中位数 332ms → 300ms；首屏 VNDB 请求 6/6/6 → 6/0/0（仍显示完整数据）；TouchGal 首次注入尝试 2613ms → 108ms，绯月 2577ms → 59ms
