# VNDB 1.0.8

本站内容跳转更闭环：新增**最近浏览**、**相似作品**与**标签 / 特征详情页**。

同一版本还包含 10-19 那批改动：搜索页分类浏览补齐「作品」入口，作品图标统一换成手柄，跨站搜索脚本同步到上游 v2.8.0（新增 Nysoure / GalZY / SakuGAL 三个资源站，站点数 35 → 38）。

## 新增

- **最近浏览**：访问过的作品 / 角色 / 版本 / 会社 / 职员会自动记进仪表盘的横向卡片条（最多 30 条，重复访问提到最前，右上角可一键清空）。版本没有截图时用关联作品封面兜底。
- **相似作品**：作品详情页多了「相似」页签，按共同标签（剧透等级 ≤ 1）反查其它作品，再按标签重合度与评分排序，最多 20 部。页面标注「按共同标签推荐，仅供参考」。
- **标签详情页**：以前点标签只会跳去「搜索这个标签的作品」，没有自己的落点。现在有 `/tag/:id`：中文标签名、分类徽章（内容 / 技术 / 性内容）、作品数、别名、清理过 BBCode 的简介与翻译按钮，下方接完整作品列表（排序 / 升降序 / 三种布局 / 触底分页）。
- **特征详情页**：`/trait/:id`，特征名、所属分组、角色数、别名、简介与翻译，下方是角色卡片（头像、原名、罗马音、性别图标、触底加载）。
- **分类浏览补上「作品」**：分类卡片原本是版本 / 会社 / 人物 / 角色 / 标签 / 特征六项，作品只能靠首页或全局搜索进。现在「作品」是分类里的第一张卡片。
- **跨站搜索新增三个资源站**：Nysoure、GalZY、SakuGAL，都支持链接直接带关键词出结果。资源站从 12 个增到 15 个，站点总数 38 个。
- **作品页排序可按链接指定**：`?sort=rating&reverse=1` 这样的链接可以直接落到指定排序（票数 / 相关度 / 评分 / 发售日 / 标题，含升降序）。排序不做记忆，每次从分类卡进来仍是默认的票数倒序。
- **SearchGal 搜索自动补一次回车**：SearchGal 会读 `?s=` 把关键词填进搜索框，但不会自己发起搜索，页面停在空白结果。现在内置浏览器加载完后会自动填入并回车。

## 变更

- **标签 / 特征的四个入口全部改指向新详情页**：标签搜索列表项、特征搜索列表项、作品搜索的标签 chip 弹卡、角色搜索的特征 chip 弹卡。
- **作品图标换成手柄**：分类卡、搜索结果里的「作品」分组、作品页页头三处统一用 `gamepad-2`，和角色 / 版本 / 会社那些图标的风格对齐。
- **跨站搜索脚本同步到 v2.8.0**：站点表与上游不再有差异，「关于」页的第三方脚本版本号一并更新。

## 修复

- **标签详情页排序会报错**：`/vn` 端点不支持按 `length` / `lastmod` / `added` 排序，选项只保留评分 / 票数 / 发售日 / 标题。
- **版本详情的最近浏览卡片是空白灰块**：原来只认版本自己的截图，改用关联作品封面兜底。
- **稻荷在应用内打不开**：站点已从 `amoebi.com` 迁到 `inarigal.com`，应用内地址已跟进并直接带关键词出结果。
- **「忧郁的弟弟」点了报证书错误**：`ttloli.com` 证书已过期，上游脚本也已移除该站，应用内一并删除。
- **TouchGal 外链偶尔还会落到过渡页**：现在直接把中转链接的 `href` 改写成真实地址，站点的 JS 抢走点击、或长按 / 键盘打开时也不会再进等待页。
- **鲲galgame 关键词参数不对**：从 `?q=` 改回站点实际使用的 `?keywords=`。
