# VNDB 1.0.9

顶栏和底部 TabBar 彻底从滚动内容里拆出来：页面来回拖动时，只有中间的内容会动，顶栏和 TabBar 不再跟着晃，也不再被下拉回弹拽变形。同时修掉了顶栏压住手机通知栏的问题，并给评分分布柱状图换成一套逐档递进的配色。

## 变更

- **顶栏固定在内容之上，不跟随拖动**：以前顶栏是内容区里的 sticky 元素，滚动到底继续下拉时会被一起带走。现在它渲染在滚动内容之外，位置固定；拖动、回弹、切页都不再影响它
- **顶栏不再压住通知栏**：Android 15 起系统强制全面屏，状态栏高度得由 WebView 自己上报。之前取的是浏览器默认值（在 App 里恒为 0），所以顶栏顶到了通知栏下面。现在改用 Capacitor 注入的实际安全区数值，顶栏留出了正确的状态栏高度
- **中间内容保留弹性回弹**：下拉到底或上拉过头时，中间内容仍会跟手做阻尼位移、松手弹回，但只有内容层在动——顶栏和底部 TabBar 完全不动
- **底部 TabBar 不再被拉伸**：底衬改成不透明纯色并单独提升为合成层，滚动时不会再跟着内容一起重绘变形
- **评分分布柱状图逐档配色**：5～10 分原先只有三档颜色（≥8 绿、≥5 蓝、其余灰），5/6/7 与 8/9/10 两两糊成一片。现在每档一个颜色，5～10 分按青 → 蓝绿 → 翠绿递进，相邻两档的色相和亮度都只差一小步，整排看过去是连贯的色带

## 新增

- **语言筛选显示国旗**：语言下拉的当前值与选项、搜索结果的语种标记、设置页的语言列表都会显示对应国旗，一眼能认出语言
- **作品简介与相关作品可整块折叠**：作品详情页的「简介」和「相关作品」两块默认收起，长页面不用一路滑到底

## 修复

- **顶栏与通知栏重叠**：见上文，改用 WebView 实际上报的安全区高度
- **下拉回弹时底部按钮栏变形**：TabBar 独立成合成层后不再参与内容重绘
- **标签 / 特征详情页顶栏跟随滚动**：这两个页面随后一并改成同样的固定顶栏结构
