# 截图

把 App 截图放进本目录，然后在根目录 README.md 的「截图」章节引用，例如：

```markdown
| 首页 | 作品详情 | 跨站搜索 |
| --- | --- | --- |
| ![](docs/screenshots/home.png) | ![](docs/screenshots/vn-detail.png) | ![](docs/screenshots/cross-search.png) |
```

建议：

- 尺寸 430×932 左右（与手机一致），PNG 格式
- 深色模式截图观感更好，也可以深浅各放一组
- 单张控制在 300KB 以内，避免仓库膨胀
